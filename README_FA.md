## نسخه ۱۲.۲ — بانک عکس داخلی و قابل مدیریت
این نسخه **عکس‌های واقعی را به‌صورت خودکار از اینترنت دانلود نمی‌کند**. بانک داخلی برای ۱۶ مدل تعریف شده و در ابتدا خالی است؛ فقط تصاویر تأییدشده‌ای که مدیر آپلود کند نمایش داده می‌شوند. این کار از نمایش عکس ساختمان یا خودروی اشتباه جلوگیری می‌کند.
- `GET /api/car-photo-bank`: فهرست مدل‌ها و وضعیت عکس‌ها (با Bearer token)
- `POST /api/car-photo-bank/{key}`: آپلود عکس واقعی با `multipart/form-data`، فیلد `photo`، حداکثر ۴ مگابایت، JPG/PNG/WebP، نیازمند توکن ورود.
- فایل‌ها در `/app/data/car_photos` ذخیره می‌شوند؛ در Liara **حتماً volume پایدار روی `/app/data`** متصل کنید.
- نمونه با curl: `curl -X POST -H "Authorization: Bearer YOUR_TOKEN" -F "photo=@santafe.jpg" https://davoodicar.liara.run/api/car-photo-bank/santafe`
- عکس‌های آپلودی باید متعلق به شما یا دارای مجوز استفاده تجاری باشند. مجوز/اعتبار تصاویر را پیش از آپلود بررسی کنید.
- تصویر خودرو فقط بعد از ثبت در بانک داخلی نمایش داده می‌شود؛ لوگوی برند فعلاً از مسیر قبلی دریافت می‌شود.
- نسخه health: `12.2.0-local-photo-bank`.

## نسخه 16.0 — معماری Market Engine

این نسخه مسیر قیمت‌گذاری را از «جستجو → GPT → قیمت» به معماری زیر تغییر می‌دهد:

`Vehicle Resolver → Source Connectors → Normalized Listings → Evidence Filter → Statistical Price Engine → LLM Explanation`

### تغییرات اصلی
- کانکتور مستقل برای دیوار، باما، همراه مکانیک، خودرو45، کارنامه و شیپور تعریف شده است.
- اگر URL یک کانکتور مستقیم در Environment تنظیم شود، همان منبع مستقیم استفاده می‌شود؛ در غیر این صورت یک جستجوی پشتیبان تجمیعی برای همه دامنه‌های بدون کانکتور اجرا می‌شود تا تعداد درخواست‌ها و احتمال 429 کمتر شود.
- خروجی تمام منابع به یک ساختار واحد تبدیل می‌شود: منبع، URL، نوع نتیجه، قیمت، سال، کارکرد، درصد تطابق و دلیل رد.
- مقاله، صفحه دسته‌بندی، نتیجه نامرتبط، سال متفاوت و نتیجه فاقد قیمت صریح وارد محاسبه قیمت نمی‌شوند.
- قیمت از متن آگهی/نتیجه استخراج می‌شود و موتور آماری با میانه، حذف پرت و میانگین وزنی بر اساس تطابق و نزدیکی کارکرد محاسبه می‌کند.
- حداقل 3 نمونه معتبر برای نمایش برآورد آماری لازم است.
- GPT دیگر مجاز به ساخت یا محاسبه قیمت نیست و فقط خلاصه فارسی را از اعداد محاسبه‌شده می‌نویسد.
- رابط کاربری تعداد نتایج، تعداد آگهی‌های پذیرفته/ردشده، علت ردها، تعداد نمونه و سطح اطمینان را نمایش می‌دهد.
- قیمت‌های مرکب فارسی مانند «۲ میلیارد و ۸۰۰ میلیون تومان» و کارکردهایی مانند «۸۰ هزار تا کارکرد» به‌صورت مستقل از سال استخراج می‌شوند.

### قرارداد کانکتور مستقیم
Endpoint باید POST JSON دریافت کند و پاسخ زیر را برگرداند:

```json
{"items":[{"url":"https://...","title":"...","price":2800000000,"mileage":30000,"year":1402,"kind":"listing"}]}
```

فیلدهای `price`، `mileage` و `year` اختیاری‌اند؛ در صورت نبود، سیستم تلاش می‌کند آن‌ها را از title/snippet استخراج کند. `kind` برای آگهی واقعی باید `listing` باشد.

### نکته عملی
این نسخه زیرساخت کانکتور مستقیم را آماده می‌کند، اما تا زمانی که API/MCP مجاز هر منبع به URLهای بالا متصل نشود، برای همان منبع از جستجوی وب پشتیبان استفاده می‌شود. بنابراین نسخه 16 کاهش وابستگی به Serper را پیاده‌سازی کرده، ولی حذف کامل آن به اتصال API/MCP واقعی نیاز دارد.

نسخه health: `16.0.0-market-engine`

## نسخه 17.0 — کانکتورهای داخلی منابع بازار

معماری v17 سه کانکتور داخلی دارد و برای آن‌ها دیگر نیازی به `*_CONNECTOR_URL` خارجی نیست:

- **Bama**: مسیر عمومی `/car` را می‌خواند، برند و مدل را از لینک‌های خود سایت پیدا می‌کند، سپس آگهی‌های منفرد `detail-*` را استخراج می‌کند. قیمت، سال و کارکرد از متن عمومی آگهی خوانده می‌شوند.
- **Hamrah Mechanic**: صفحه عمومی `cars-for-sale` را بررسی می‌کند و آگهی‌های منفرد را باز می‌کند تا قیمت، سال و کارکرد از خود صفحه آگهی تأیید شوند.
- **Khodro45**: صفحات عمومی قیمت را بررسی می‌کند. لینک‌های `/mag/`, `/blog/`, `/news/` هرگز به‌عنوان شاهد قیمت مستقیم پذیرفته نمی‌شوند. داده این منبع با نوع `market_price` و وزن کمتر از آگهی واقعی وارد موتور آماری می‌شود.

ترتیب دسترسی هر منبع:
1. اگر `*_CONNECTOR_URL` تنظیم شده باشد، کانکتور خارجی/رسمی اولویت دارد.
2. در غیر این صورت کانکتور داخلی عمومی اجرا می‌شود.
3. اگر کانکتور داخلی نتیجه ندهد یا سایت دسترسی را محدود کند، Search fallback موجود در v16 فعال می‌شود.

### محدودیت‌های مهم
- کانکتورها فقط صفحات عمومی را می‌خوانند؛ login، CAPTCHA، anti-bot یا محدودیت دسترسی سایت‌ها دور زده نمی‌شود.
- ساختار HTML سایت‌ها ممکن است تغییر کند؛ هر کانکتور مستقل است تا فقط همان ماژول نیاز به اصلاح داشته باشد.
- کانکتور باما بر اساس ساختار عمومی مشاهده‌شده در `bama.ir/car` و صفحات مدل/آگهی ساخته شده است.
- همراه مکانیک ممکن است همه مدل‌های بازار را در صفحه نخست `cars-for-sale` نشان ندهد؛ در این حالت موتور از Search fallback استفاده می‌کند.
- خودرو45 در وب عمومی بیشتر مرجع قیمت/تخمین است تا feed پایدار آگهی؛ بنابراین داده آن با آگهی واقعی یکسان وزن داده نمی‌شود.
- اجرای live از محیط ساخت حاضر ممکن نبود چون DNS خروجی container فعال نبود. Parserها با fixtureهای مبتنی بر ساختار فعلی صفحات عمومی تست شده‌اند.

Health version: `17.0.0-native-connectors`
