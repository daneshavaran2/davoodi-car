# نسخه ۲۰ — اصلاح تشخیص سال گفتاری

این بسته بر اساس نسخه ۱۹ ساخته شده است.

- رفع خطای عبارت منظم تشخیص سال چهاررقمی بدون پیشوند «مدل»
- جلوگیری از حذف سال معتبر وقتی کارکرد خودرو هم ذکر می‌شود
- حفظ اصلاح قبلی فیدلیتی / فیتیلی
- آزمایش واقعی تابع parse_voice با سال‌های 2025 و 1403 و کارکرد ۵۰ هزار کیلومتر

## استقرار
فایل ZIP را به‌عنوان پروژه Docker روی Liara بارگذاری کنید و متغیرهای محیطی نسخه فعلی را حفظ کنید.
استقرار واقعی روی Liara و build فرانت‌اند در این محیط انجام نشده است.
