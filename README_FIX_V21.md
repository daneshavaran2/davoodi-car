# نسخه ۲۱ — Market Source Fix

این نسخه بر پایه v20 ساخته شده و مشکل «نتیجه پیدا شد ولی همه حذف شدند» را در موتور بازار هدف گرفته است.

## تغییرات اصلی
- جست‌وجوی پشتیبان از حالت یک Query مشترک برای چند دامنه به **جست‌وجوی جداگانه برای هر منبع** تغییر کرد.
- Query هر منبع با نیت درست ساخته می‌شود: «آگهی فروش خودرو» برای سایت‌های آگهی و «قیمت روز خودرو» برای منابع مرجع قیمت.
- صفحات مقاله، بررسی، مشخصات فنی، راهنمای خرید، اخبار، کاتالوگ و صفحات دسته‌بندی قبل از نمایش به‌عنوان منبع قیمت کنار گذاشته می‌شوند.
- وضعیت هر سایت اکنون `نتیجه خام` و `شاهد معتبر` را جدا گزارش می‌کند.
- اگر فقط ۱ یا ۲ شاهد واقعی وجود داشته باشد، قیمت‌های مشاهده‌شده و بازه آن‌ها نمایش داده می‌شود اما **میانگین بازار ساخته نمی‌شود**.
- برای ۳ نمونه معتبر یا بیشتر، موتور آماری قبلی با حذف پرت و وزن‌دهی اجرا می‌شود.
- کارت‌های منابع واضحاً نامرتبط دیگر در UI نمایش داده نمی‌شوند؛ دلیل حذف در بخش تشخیصی باقی می‌ماند.
- نسخه health به `21.0.0-market-source-fix` ارتقا یافت.

## تست‌های انجام‌شده
- مقاله باما با عنوان «بررسی خودرو» به‌عنوان article رد شد.
- URL آگهی باما به‌عنوان listing پذیرفته شد.
- Query هدفمند باما برای «هیوندای سانتافه 2025» ساخته شد.
- یک شاهد واقعی => limited_evidence=true و price_average=null.
- تست یکپارچه بدون اینترنت: یک مقاله + دو آگهی واقعی => مقاله از خروجی منبع حذف شد، ۲ شاهد واقعی نگه داشته شدند و میانگین بازار صادر نشد.

## نکته استقرار
برای عملکرد جست‌وجوی پشتیبان، `AVALAI_API_KEY` باید در Environment لیارا تنظیم باشد. منابعی که کانکتور مستقیم یا عمومی آن‌ها نتیجه معتبر ندهد، با جست‌وجوی هدفمند بررسی می‌شوند.
