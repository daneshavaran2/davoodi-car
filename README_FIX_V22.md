# یادداشت انتشار Davoodi Car v22 — Market Intelligence Edition

## تغییرات
۱. امتیاز کیفیت هر شاهد براساس تطابق مدل، برند، سال، تیپ، کارکرد، شهر، قدمت واقعی انتشار و نوع منبع؛ خروجی ۰ تا ۱۰۰ و نه احتمال درستی قیمت.  
۲. حذف آگهی قدیمی (با تاریخ انتشار قابل اعتماد، پیش‌فرض ۶۰ روز)، لینک و آگهی تکراری، قیمت پرت. در نبود تاریخ انتشار، قدمت «نامعلوم» می‌ماند و امتیاز کمتر می‌گیرد.  
۳. جداسازی آگهی فروش از قیمت مرجع؛ قیمت مرجع وزن ۴۵٪ آگهی دارد؛ مقاله قیمت‌ساز نیست. برای برآورد حداقل ۳ شاهد قیمت‌دار شامل ۲ آگهی فروش لازم است.  
۴. محاسبه قیمت پیشنهادی و بازه مبتنی بر شواهد، میانه، تعداد آگهی معتبر، تعداد منابع مستقل و امتیاز کیفیت.  
۵. تشخیص گفتار فیدلیتی و سانتافه نیوفیس، با کاندیداهای تأییدپذیر و فقط یک سؤال ابهام مهم.  
۶. داشبورد React با خلاصه مدیریتی، جدول منبع و نمودار توزیع قیمت؛ واکنش‌گرا برای موبایل.  
۷. تست‌های آفلاین داده‌های ساختگی برای حذف مقاله/قدیمی/تکراری/پرت، گفتار، آمار و یکپارچگی.

## راه‌اندازی Liara
ZIP را استخراج کنید، پروژه Docker را از ریشه استقرار دهید و در داشبورد Liara متغیرهای `ADMIN_PASSWORD` و `SESSION_SECRET` و در صورت نیاز `AVALAI_API_KEY` و دیگر متغیرها را تنظیم کنید. فایل `.env.example` فقط الگو است. پس از انتشار `/api/health` باید نسخه `22.0.0-market-intelligence` را گزارش کند. تنظیم `DB_PATH` باید به فضای پایدار اشاره کند.

## محدودیت‌ها
در محیط ساخت، دسترسی نصب وابستگی npm برقرار نبود؛ فرانت‌اند از نظر نحوی با parser TypeScript/JSX بررسی شده، اما build کامل Docker و استقرار زنده تایید نشده است. منابع بازار و APIهای طرف ثالث باید در محل استقرار با آگهی واقعی آزموده شوند.
