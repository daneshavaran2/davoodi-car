# Davoodi Car v23 — Search QA + UX

- اصلاح جست‌وجوی دستی که قبلاً `brand/model/year/mileage=null` می‌فرستاد؛ استخراج سروری قبل از جست‌وجو.
- جلوگیری از جست‌وجو بدون مدل قابل تشخیص؛ خطای 422 با متن اصلاح کاربردی.
- اصلاح کش با کلید شامل مشخصات واقعی و قابلیت refresh واقعی.
- جست‌وجوی موازی چند منبع با سقف پردازش برای جلوگیری از timeout.
- خواندن قیمت، سال و کارکرد رشته‌ای فارسی از JSON کانکتورها.
- عدم پذیرش لینک خارج از دامنه رسمی منبع.
- اصلاح fallback تشخیص گفتاری مرورگر: سال ۱۴۰۳ با کارکرد اشتباه نمی‌شود.
- پیام خطا نزدیک ورودی، نمونه‌های کلیک‌پذیر، نمایش مدل شناسایی‌شده، ناوبری سریع نتایج، حداقل سایز ۴۴px موبایل.
- تشخیص غیرفعال بودن جست‌وجوی AvalAI؛ نمایش آن در وضعیت منابع به جای «بدون نتیجه».
- رفع نشت اتصال‌های SQLite در درخواست‌های متعدد.
- تست‌های خودکار API، کانکتورها، موتور قیمت، کش، امنیت و قراردادهای رابط.

**محدودیت:** آزمایش قیمت بازار زنده بدون کلید معتبر و دسترسی به سایت‌ها ممکن نبود. build واقعی Vite/Docker و تست فیزیکی میکروفن در موبایل هنوز تأیید نشده‌اند.
