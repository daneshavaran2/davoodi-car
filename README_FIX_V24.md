# Davoodi Car v24 — اصلاحات امنیت و کیفیت قیمت

این بسته بر اساس نسخه ۲۳ تهیه و پیش از انتشار در **تست‌های آفلاین** بررسی شده است. راهنمای اصلی در `README.md` و گزارش پذیرش در `docs/RELEASE_V24.md` است.

ویژگی‌های کلیدی: حذف مبلغ کارمزد از قیمت، تشخیص درست کارکرد، تفکیک تیپ و وضعیت بدنه، تشخیص محافظه‌کار صفرکیلومتر، خواندن JSON-LD از صفحه آگهی عمومی، محدودکردن تلاش ورود، جست‌وجوی هم‌زمان، کش با سقف سنی، مشاهده مرحله واقعی جست‌وجو، ارتقای دسترس‌پذیری موبایل.

**نسخه سلامت:** `24.0.0-quality-security`.

**هشدار انتشار:** تست بازار زنده، build npm/Docker و تست موبایل واقعی در محیط ساخت امکان‌پذیر نبود. این نسخه نامزد انتشار است، نه تضمین بدون باگ بودن روی Liara.
