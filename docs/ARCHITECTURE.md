# معماری Davoodi Car

## جریان داده
ورودی متنی/گفتاری → استخراج برند، مدل، تیپ، سال و کارکرد → جست‌وجو در منابع → نرمال‌سازی → حذف موارد نامعتبر/تکراری → محاسبه آماری قیمت → پاسخ با لینک منابع.

## اجزا
- React/Vite: رابط کاربری RTL
- FastAPI: احراز هویت، API و orchestration
- Connectors: هر منبع یک ماژول جدا؛ خطای یک منبع نباید کل استعلام را متوقف کند
- Cache/Database: کاهش درخواست‌های تکراری و ثبت تاریخچه
- Docker: استقرار روی Liara

## قواعد مهم
- عدم ساخت قیمت توسط مدل زبانی
- رد کردن صفحات مقاله به‌عنوان آگهی
- رعایت timeout، rate limit و خطای قابل گزارش
- نگهداری کلیدها در environment و عدم ثبت در Git
- بازبینی دوره‌ای parser با تغییر ساختار سایت‌ها
