# راهنمای توسعه‌دهنده

1. مخزن را clone و branch جدا ایجاد کنید.
2. وابستگی‌های frontend را با `npm install` نصب و با `npm run dev` اجرا کنید.
3. وابستگی‌های backend را از `backend/requirements.txt` نصب کنید و FastAPI را با `uvicorn main:app --reload` از پوشه backend اجرا کنید.
4. برای منبع جدید، فایل مستقل در `backend/connectors/` بسازید؛ قرارداد داده را رعایت کنید و نمونه‌های واقعی و تست واحد اضافه کنید.
5. تغییرات UI را در `frontend/src/` نگه دارید؛ RTL و موبایل را تست کنید.
6. خطاها را بدون افشای API key یا اطلاعات حساس ثبت کنید.
7. قبل از Pull Request، build فرانت‌اند، تست‌ها و سلامت backend را اجرا کنید.
8. README و مستندات مربوط به هر قابلیت جدید را به‌روز کنید.

## استقرار Liara
از Dockerfile ریشه استفاده کنید؛ environment variables را در داشبورد Liara تنظیم کنید. در صورت استفاده از SQLite، ذخیره‌سازی دائمی یا پایگاه داده مدیریت‌شده ضروری است. پس از استقرار، `/api/health` را کنترل کنید.

## اصول دریافت داده
فقط صفحات عمومی و مجاز؛ بدون دورزدن CAPTCHA یا ورود. در نبود داده معتبر، پیام «داده کافی نیست» برگردانید، نه قیمت حدسی.
