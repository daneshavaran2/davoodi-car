# استقرار آزمایشی Davoodi Car v24 روی Liara

## پیش‌نیازها
- پروژه Docker با سورس کامل نسخه ۲۴ و فایل Dockerfile در ریشه.
- `ADMIN_PASSWORD` قوی و `SESSION_SECRET` تصادفی حداقل ۳۲ کاراکتری.
- اگر جست‌وجوی تکمیلی می‌خواهید، کلید واقعی `AVALAI_API_KEY` در متغیرهای محیطی Liara.
- مسیر DB دائمی (`DB_PATH`) و پشتیبان منظم.

## اقدامات
۱. ZIP را استخراج کنید و پروژه را با Docker build منتشر کنید. فایل `.env` واقعی را در GitHub قرار ندهید.
۲. `/api/health` و `/api/readiness` را باز کنید.
۳. با یک رمز اشتباه و یک رمز درست رفتار Login را تست کنید؛ آزمایش تعداد زیاد رمز اشتباه فقط در محیط staging.
۴. عبارت «فیدلیتی پرایم ۱۴۰۳ کارکرد ۵۰ هزار» و «سانتافه ۲۰۲۵ صفر کیلومتر» را با ورود دستی و گفتاری آزمایش کنید.
۵. در صفحه جست‌وجو، وضعیت پیشرفت واقعی سایت‌ها را ببینید و بررسی کنید که پس از پایان جست‌وجو، پیام وضعیت صحیح نمایش داده شود.
۶. برای هر قیمت واقعی روی لینک منبع کلیک کنید و تطابق را دستی بررسی کنید.
۷. اگر منبع یا کلید جست‌وجو در دسترس نبود، از نمایش عدد حدسی جلوگیری کنید.

## rollback
نسخه قبلی v23 و DB را قبل از انتشار پشتیبان بگیرید. در صورت خطای حیاتی و تا زمان رفع آن، deployment را به نسخه پایدار قبلی برگردانید؛ DB نسخه قبل باید سازگار باشد.

**نکته:** فقط پس از موفقیت آزمون‌های عملی روی Liara نسخه را Production-Ready بنامید.
