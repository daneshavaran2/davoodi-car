# معرفی کامل پروژه داودی کار

## ۱. هدف
سامانه فارسی هوش بازار خودرو برای نمایشگاه اتومبیل داودی. هدف، دریافت مشخصات خودرو از گفتار یا فرم، پیدا کردن شواهد قیمت از منابع مختلف بازار ایران و نمایش برآورد مستند به کارکنان نمایشگاه است. مدیریت موجودی داخلی نمایشگاه در محدوده اصلی این نسخه نیست.

## ۲. کاربران
- مالک و کارکنان نمایشگاه: جست‌وجو، مقایسه و بررسی شواهد قیمت
- مدیر فنی: تنظیم منابع، بررسی خطاها و استقرار
- در نسخه‌های آینده: نمایشگر یا کیوسک برای مراجعه‌کننده

## ۳. قابلیت‌های هدف
| قابلیت | توضیح | وضعیت |
|---|---|---|
| ورودی فارسی | متن، فرم و گفتار برای برند، مدل، تیپ، سال، کارکرد | طراحی‌شده؛ نیازمند بازبینی سورس کامل |
| کاتالوگ خودکار خودرو | کشف مدل و نام‌های معادل بدون ورود دستی | طراحی‌شده؛ نیازمند تست |
| اتصال به منابع | باما، همراه مکانیک، خودرو۴۵، API رسمی در صورت دسترسی | فایل کانکتورها در GitHub ثبت شده؛ تست زنده تأیید نشده |
| یکسان‌سازی | تبدیل نام‌ها، سال و کارکرد به قالب واحد | طراحی‌شده؛ یکپارچگی با backend باید بررسی شود |
| برآورد قیمت | آمار روی شواهد معتبر، حذف موارد نامرتبط | طراحی‌شده؛ تست end-to-end نشده |
| تاریخچه و مقایسه | ثبت و مرور استعلام‌ها | در نسخه‌های قبلی مطرح شده؛ سورس کامل هنوز منتقل نشده |
| انتشار Liara | Docker و تنظیمات محیطی | Dockerfile ثبت شده؛ استقرار تأیید نشده |

## ۴. آنچه واقعاً در GitHub انجام شده
- ایجاد مخزن مستقل `daneshavaran2/davoodi-car`
- ثبت `README.md` و اسناد اولیه معماری و مشارکت
- ثبت `.gitignore`، `.dockerignore`، `.env.example`، `Dockerfile`
- ثبت `frontend/package.json` و `frontend/index.html`
- ثبت `backend/requirements.txt` و ماژول‌های `backend/connectors/`

**توجه:** تا زمان اضافه شدن `backend/main.py`، `frontend/src/main.jsx`، `frontend/src/style.css` و فایل‌های لازم دیگر، این مخزن نسخه قابل اجرا نیست. ثبت یک کانکتور به معنی تأیید عملکرد آن روی سایت زنده نیست.

## ۵. محدودیت‌ها
- دسترسی و ساختار سایت‌ها ممکن است تغییر کند؛ API عمومی همه منابع تضمین نشده است.
- قیمت آگهی، قیمت معامله قطعی نیست.
- سامانه نباید قیمت یا منبع ساختگی تولید کند.
- صفحات خبر/مقاله نباید به‌عنوان آگهی فروش محاسبه شوند.
- شرایط استفاده، robots.txt و محدودیت‌های دسترسی هر سایت باید رعایت شود.
