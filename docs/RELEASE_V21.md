# Release v21 — Market Source Fix

## مشکل
نسخه قبلی ممکن بود چند نتیجه خام از جست‌وجوی عمومی بگیرد اما همه آن‌ها مقاله، مشخصات فنی یا صفحات نامرتبط باشند؛ بنابراین ۰ شاهد معتبر برای محاسبه باقی می‌ماند.

## اصلاحات
- جست‌وجوی جداگانه برای هر دامنه به جای Query مشترک چند سایت
- Query هدفمند «آگهی فروش خودرو» برای منابع آگهی و «قیمت روز خودرو» برای منابع مرجع
- افزودن سال معادل میلادی/شمسی به Query جست‌وجو
- حذف مقاله، بررسی، مشخصات فنی، راهنما، خبر، کاتالوگ و صفحه دسته‌بندی از منبع قیمت
- گزارش جداگانه تعداد نتیجه خام و شاهد معتبر برای هر سایت
- ۱ یا ۲ شاهد واقعی: نمایش «شواهد محدود» و بازه مشاهده‌شده، بدون ساخت میانگین بازار
- ۳ شاهد یا بیشتر: ادامه تحلیل آماری با حذف پرت
- حذف کارت‌های واضحاً نامرتبط از رابط کاربری
- Health version: `21.0.0-market-source-fix`

## تست انجام‌شده
تست‌های آفلاین بک‌اند تایید کردند:
1. صفحه «بررسی خودرو» رد می‌شود.
2. URL آگهی باما پذیرفته می‌شود.
3. Query باما برای سانتافه 2025 به‌صورت هدفمند و همراه 1404 ساخته می‌شود.
4. یک شاهد واقعی باعث `limited_evidence=true` و `price_average=null` می‌شود.
5. سناریوی یک مقاله + دو آگهی واقعی، مقاله را از کارت منابع حذف و دو شاهد را بدون میانگین حفظ می‌کند.

Build کامل فرانت‌اند در محیط ساخت فعلی به دلیل در دسترس نبودن نصب npm تایید نشده و باید هنگام استقرار Docker روی Liara کنترل شود.
