# گزارش انتشار Davoodi Car v22

## مسئله نسخه‌های قبل
نسخه قبلی با وجود نتایج خامِ موتور جست‌وجو، گاهی هیچ آگهی واقعی قیمت‌دار و مرتبط پیدا نمی‌کرد. علاوه بر آن، امتیاز اعتبار هر شاهد، حذف آگهی قدیمی و تکراری، و نمایش مدیریتی شفاف وجود نداشت.

## اصلاحات نسخه ۲۲
۱. امتیاز کیفیت مدل/برند/سال/تیپ/کارکرد/شهر/زمان/منبع.
۲. حذف خودکار آگهی تکراری، قدیمی یا نامرتبط و قیمت پرت.
۳. تفکیک آگهی فروش از مرجع قیمت و منع قیمت‌گذاری از روی مقاله.
۴. اعلام برآورد فقط با سه شاهد و دست‌کم دو آگهی واقعی.
۵. نمایش قیمت پیشنهادی، میانه، بازه واقعی، تعداد نمونه، تنوع سایت، سطح اعتماد، نمودار و جدول شواهد.
۶. تشخیص نام‌های گفتاری فیدلیتی و سانتافه نیوفیس، با سؤال تکمیلی اولویت‌دار.
۷. تست‌های آفلاین برای نمونه‌های ساختگی و جلوگیری از رگرسیون.

## وضعیت تحویل
- ZIP کامل v22 همراه سورس و فایل‌های آماده Docker ایجاد شده است.
- ۱۱ تست آفلاین v22 و تست‌های قبلی v21 موفق شده‌اند.
- فایل JSX از نظر نحوی بررسی شده است.
- npm build، build Docker، جست‌وجوی زنده و استقرار Liara هنوز تأیید نشده‌اند.
- برای دریافت سورس همگام‌شده در GitHub، وضعیت فایل‌های `backend/main.py` و `frontend/src/main.jsx` را بررسی کنید؛ در صورت نبودن آن‌ها از ZIP نسخه ۲۲ استفاده شود.
