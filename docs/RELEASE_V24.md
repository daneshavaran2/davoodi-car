# Davoodi Car v24 — Release Candidate

**تاریخ:** ۱۲ نوامبر ۲۰۲۶ · **وضعیت:** آماده استقرار آزمایشی، نه گواهی تولید/قیمت زنده.

## خطاهای اصلاح‌شده

| موضوع | قبل | نسخه ۲۴ |
|---|---|---|
| مبلغ خودرو | احتمال انتخاب کارمزد/پیش‌پرداخت | استخراج بافتی؛ مقدار مبهم رد می‌شود |
| کارکرد گفتاری | ممکن بود سال ۱۴۰۳ به‌جای ۵۰٬۰۰۰ ثبت شود | تشخیص مبتنی بر عبارت «کارکرد/کیلومتر»، عدم تفسیر سال به‌صورت کارکرد |
| تیپ | امکان ادغام پرایم/پرستیژ | تطبیق دقیق تیپ؛ تیپ نامعلوم به بررسی انسانی |
| صفر/کارکرده | «تحویل فوری» گاهی صفر تلقی می‌شد | فقط نشانهٔ صریح صفر یا عدد کارکرد؛ تعارض رد می‌شود |
| وضعیت بدنه | یکسان‌سازی خودروی سالم و رنگ‌دار | تطبیق یا رد؛ عدم اعمال ضریب کاهش ارزش بدون داده |
| امنیت ورود | عدم محدودیت تلاش‌ها و خروج ضعیف | محدودیت ۵ تلاش در ۱۵ دقیقه، نشست تصادفی و ابطال در SQLite |
| جست‌وجوی منابع | جست‌وجوی گسترده/نامرتبط | Query دامنه‌ای، سال شمسی/میلادی جایگزین، استخراج JSON-LD و تاریخ معتبر در حد دسترسی عمومی |
| اعتبار شواهد | مقاله/آگهی قدیمی/نامشخص | رد یا فهرست نیازمند بررسی؛ آمار فقط از نمونه‌های تاییدشده |
| جست‌وجوی طولانی | انتظار یک‌پارچه بدون پیشرفت واقعی | API وظیفه + polling، صف محدود، وضعیت واقعی هر دامنه |
| کش | نتیجه قدیمی احتمالی | TTL مشخص، سقف ۶ ساعت برای fallback قدیمی همراه هشدار |
| موبایل/RTL | رابط پیچیده در مراحل | فرم کوتاه، پرسش مشخص و خلاصه قیمت؛ CSS موبایل و کاهش حرکت |
| استاتیک در Docker | مسیر frontend با ساختار container منطبق نبود | تعریف صریح `FRONTEND_DIST=/app/frontend/dist` |

- **برچسب شواهد منبع:** بعد از ارزیابی نهایی آگهی، اگر همه موارد رد شده باشند منبع دیگر به‌اشتباه «شواهد معتبر» نمایش داده نمی‌شود (تست رگرسیون افزوده شد).

## شناسه نسخه

`GET /api/health` → `24.0.0-release-candidate`

## محدودیت‌های باقی‌مانده

- دسترسی زنده و پایدار به آگهی‌های باما، همراه مکانیک، خودرو۴۵ و سایر دامنه‌ها **تأیید نشده است**؛ تغییر HTML، محتوای JavaScript، محدودیت درخواست یا 403 می‌تواند باعث صفر شاهد معتبر شود.
- بدون تاریخ انتشار/مشخصات تأییدپذیر، سامانه آگهی را به‌عنوان شاهد قیمت نهایی حساب نمی‌کند. ممکن است نتیجه درست **«شواهد کافی نیست»** باشد.
- Docker build، Vite build، یک UI end-to-end واقعی با سایت Liara و عملکرد موبایل واقعی در این محیط انجام نشده‌اند.
- جست‌وجو در یک process قابل استفاده است؛ برای چند replica صف و DB خارجی لازم است.
- امنیت فعلی بر رمز مشترک مدیریت است؛ نقش‌های کارکنان، MFA، سیاست بازیابی و log audit سازمانی پیاده نشده‌اند.

## شرایط تبدیل به انتشار تولید

موفقیت GitHub Actions، ساخت Docker، تست مرورگر واقعی روی UI مستقرشده، آزمون حداقل چند مدل ایرانی/چینی/وارداتی با لینک آگهی، تایید backup DB و تست restart/timeout لازم است.
