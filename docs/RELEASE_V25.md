# انتشار Davoodi Car v25 — نتیجه در یک نگاه و راهبرد هوش مصنوعی

**وضعیت:** آمادهٔ آزمایش روی Liara، نه تضمین کیفیت داده زنده یا انتشار نهایی.

## فایل‌های جدید
- `frontend/src/QuickVerdict.jsx` — کارت نتیجه در یک نگاه بالای گزارش کامل
- `frontend/src/quickDecision.mjs` — منطق امن و مستقل ساخت خلاصه
- `qa/test_v25_quick_glance.mjs` — سناریوهای قبول/رد قیمت و وضعیت‌های ناقص
- `docs/AI_AND_3SECOND_UX_V25.md` — توصیه‌های توسعه AI و هدف‌گذاری کارایی

## رفتار جدید
- **برآورد قیمت فقط از شواهد واقعی:** حداقل ۳ شاهد شامل ۲ آگهی مستقیم، با مبلغ عددی معتبر؛ داده ناکافی هیچ عددی ساخته نمی‌شود.
- تطبیق وضعیت صفر/کارکرده بر اساس کارکرد درخواست؛ در حالت نامشخص، ابتدا تکمیل مشخصات.
- شواهد محدود، داده قدیمی و بدون نتیجه، پیام‌های مستقل دارند.
- ۱–۲ لینک معتبر اولیه، کیفیت داده، شمار منبع و زمان مشاهده در اولین کارت؛ محتوای مفصل بازشدنی.

## آزمایش
- تست‌های آفلاین Python نسخه‌های ۲۱، ۲۲، ۲۳ و ۲۴ موفق.
- تست‌های آفلاین رابط نسخه‌های قدیمی و سناریوهای جدید کارت نتیجه موفق.
- بررسی نحوی JSX با TypeScript parser بدون خطا.
- `npm install --offline` به‌علت موجود نبودن `lucide-react` در کش شکست خورد؛ بنابراین **build کامل Vite تأیید نشده**.
- تماس با سایت‌های زنده و تست مرورگر موبایل/عملکرد واقعی کمتر از سه ثانیه هنوز انجام نشده.

## مراحل پذیرش انتشار
۱. عبور تست GitHub Actions (Python + Node + Vite + Docker). ۲. تست با اینترنت و کانکتورهای مجاز روی Liara. ۳. بررسی حداقل ۱۵ استعلام نمونه با آگهی واقعی. ۴. تست کاربر واقعی در موبایل و دسکتاپ با معیار تشخیص وضعیت نتیجه زیر سه ثانیه. ۵. کنترل امنیت توکن و محدودیت نرخ.
