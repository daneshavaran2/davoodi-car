# Davoodi Car v27 — اصلاح مسیر استخراج و تشخیص خطا

**وضعیت در ۱۲ نوامبر ۲۰۲۶:** اصلاحات و تست‌های رگرسیون در GitHub نوشته شدند. دسترسی زندهٔ Liara، دسترسی سایت‌های آگهی و ساخت Docker هنوز با شواهد مستقل تأیید نشده‌اند؛ این نسخه تا عبور از Build و نمونه‌برداری واقعی «آزمایشی» است.

## دلیل نمایش «قیمت قابل اتکا پیدا نشد» با صفر آگهی
ممکن است (۱) Chromium در کانتینر کار نکند، (۲) یکی از سایت‌ها HTTP 403/429 یا کپچا بدهد، (۳) صفحات فهرست هنوز آگهی هدف را رندر نکرده باشند، (۴) URL آگهی کوتاه باشد و پذیرفته نشود، (۵) مدل/تیپ/سال/کارکرد/قیمت ناقص باشد و فیلتر نهایی آن را رد کند، یا (۶) جست‌وجوی تکمیلی در Liara کلید نداشته باشد. صفر نتیجه به معنای نبود خودرو در بازار نیست.

## تغییرات قابل بررسی
- دیوار: لینک کوتاه `/v/ID` و لینک `/v/slug/ID` به‌عنوان URL آگهی پذیرفته می‌شوند؛ در صورت نبود تطابق جست‌وجو با سال/تیپ دقیق، جست‌وجوی عمومی‌تر تکرار می‌شود.
- باما: لینک دسته مدل مستقیماً بررسی می‌شود؛ اگر صفحه دسته اصلی کارت نداشت، کارت‌های صفحه قبلی نیز ارزیابی می‌شوند.
- همراه مکانیک: علاوه بر صفحه عمومی، لینک‌های دسته مدل مرتبط نیز بررسی می‌شوند و محدودیت ۲۵ آگهی اول صفحه عمومی کاهش یافت.
- Playwright: در صفحه جزئیات منتظر لینک آگهی دیگر نمی‌ماند (کاهش تأخیر غیرضروری)؛ بارگذاری فهرست و جزئیات انتظار متفاوت دارد.
- استخراج: مبلغ عددی بدون واژهٔ «تومان» فقط در کادر صریح قیمت همان آگهی بررسی می‌شود؛ اقساط، کارمزد و قیمت‌های متناقض/نامعتبر رد می‌شوند.
- جست‌وجوی تکمیلی: اسنیپت موتور جست‌وجو **به‌عنوان سند قیمت استفاده نمی‌شود**؛ فقط صفحه واقعی منبع با قیمت و مدل قابل بررسی می‌تواند وارد آمار شود.
- اعتبارسنجی: اگر قیمت کارت و صفحه جزئیات بیش از حد متفاوت باشند، آگهی مردود می‌شود.
- گزارش: وضعیت هر منبع، تعداد خام، تعداد ردشده، خطای خواندن جزئیات و سه علت پرتکرار رد ثبت می‌شود.
- کش: پاسخ صفر/بدون مدرک حداکثر ۴۵ ثانیه (پیش‌فرض) نگه داشته می‌شود، تا خطای موقت ۱۵ دقیقه در UI قفل نشود.
- رابط کاربر: خرابی منابع و تعداد داده خام مستقیماً زیر پیام قیمت نشان داده می‌شود؛ دکمهٔ «بررسی اجرای Playwright در سرور» تست مستقیم Chromium/JavaScript را بعد از ورود فراهم می‌کند.
- Dockerfile: Build علاوه بر ساخت Vite، تست `test_v26_playwright.py`، `test_v27_reliability.py` و یک smoke test مرورگر با کاربر غیر root را اجرا می‌کند. تست‌ها وابسته به سایت‌های خارجی نیستند.

## تنظیمات Liara
پلتفرم حتماً **Docker** با فایل `Dockerfile` ریشه همین مخزن باشد.

```env
MARKET_FETCH_MODE=playwright
MAX_CONCURRENT_BROWSERS=1
MAX_DETAIL_PAGES_PER_SOURCE=6
MAX_FALLBACK_DETAIL_PAGES=5
EMPTY_RESULT_CACHE_TTL=45
SEARCH_CACHE_TTL=900
```

همچنین `ADMIN_PASSWORD` و `SESSION_SECRET` با حداقل ۳۲ نویسه، `DB_PATH` روی فضای ذخیره‌سازی پایدار و **در صورت وجود کلید قانونی جست‌وجوی تکمیلی** `AVALAI_API_KEY` را در Secretهای Liara تنظیم کنید. کلید محرمانه را در GitHub قرار ندهید. `MAX_CONCURRENT_BROWSERS=2` فقط برای منابع دارای حافظه کافی توصیه می‌شود.

**نکته مهم:** در غیاب `AVALAI_API_KEY`، فقط کانکتورهای داخلی کار می‌کنند؛ برخی سایت‌ها ممکن است صفحه عمومی را مسدود کرده باشند یا API مجاز لازم داشته باشند. نصب Playwright مجوز یا دسترسی تضمینی به داده‌ها فراهم نمی‌کند.

## پنج آزمون الزامی پس از استقرار
۱. `GET /api/health` باید `27.0.0-market-reliability` برگرداند؛ مقدار قدیمی به معنی استقرار نشدن کد جدید است.

۲. `GET /api/readiness` باید `database:ok` و `market_fetch_mode:playwright` داشته باشد. این فقط بررسی تنظیمات است، نه تضمین استخراج.

۳. پس از ورود، یک جست‌وجو اجرا کرده و «بررسی اجرای Playwright در سرور» را بزنید. این دکمه با توکن کاربر به `GET /api/browser-check` درخواست می‌دهد. نتیجه `chromium/javascript:ok` یعنی مرورگر اجرا می‌شود؛ هنوز دسترسی سایت‌ها را ثابت نمی‌کند.

۴. استعلام «فیدلیتی پرایم ۱۴۰۳ کارکرد ۵۰ هزار کیلومتر» را آزمایش کنید. برای هر منبع، **تعداد خام، تعداد معتبر و دلیل رد** را بررسی کنید. یک URL واقعی را باز کرده و عنوان، قیمت، سال، کارکرد و تیپ را با خروجی سامانه تطبیق دهید.

۵. در مجموع حداقل ۲۰ آگهی تازه از هر سایت (در صورت دسترسی مجاز) را دستی تطبیق دهید. برای قیمت بدون منبع/تیپ نامشخص/تاریخ نامشخص برآورد قطعی صادر نکنید. اگر 403/429/CAPTCHA رخ داد، آن را خطای دسترسی بنامید، نه «هیچ آگهی وجود ندارد».

## معیار انتشار نهایی
- CI GitHub Actions یا Build مستقل Docker باید سبز باشد. در بررسی قبلی Actions بدون Runner و بدون Step متوقف می‌شد؛ علت می‌تواند محدودیت حساب/Runner باشد و نشانه خطای کد نیست.
- تست داخلی Chromium روی Liara اجرا شود.
- حداقل ۳ شاهد مرتبط برای برآورد (شامل ۲ آگهی فروش) با تیپ/سال/کارکرد سازگار و لینک قابل بررسی وجود داشته باشد.
- در منبع مسدود، قیمت ساختگی نمایش داده نشود.
- آگهی کوتاه دیوار، مبلغ عددی و عدم‌تطابق کارت و جزئیات با تست‌های رگرسیون کنترل شوند.

**مرز تضمین:** هیچ کدی نمی‌تواند دقت همیشگی قیمت همهٔ خودروها یا دسترسی همیشگی به همهٔ سایت‌ها را تضمین کند. برای پوشش پایدار بازار، API/فید مجاز هر منبع و پایش روزانه تغییرات ساختار لازم است.
