# راهنمای استقرار نسخه ۲۹ داودی‌کار روی Liara

**هدف:** کاربر فقط نام خودرو را می‌گوید/می‌نویسد؛ سامانه بازه قیمت پیشنهادی آگهی‌های واقعی را بر اساس **سال، تیپ و صفر/کارکرده** جدا می‌کند. در کنار هر بازه لینک نام‌دار همان منبع دیده می‌شود. اطلاعات فنی منابع در بخش بازشدنی قرار می‌گیرند تا رابط ساده بماند.

## ۱. پوشش واقعی منابع

| منبع | مسیر دریافت موجود | نیاز برای پوشش واقعی |
|---|---|---|
| دیوار | کانکتور عمومی داخلی Playwright | اجرای Chromium و دسترسی عمومی سایت |
| باما | کانکتور عمومی داخلی Playwright | اجرای Chromium و دسترسی عمومی سایت |
| همراه مکانیک | کانکتور عمومی داخلی Playwright | اجرای Chromium و دسترسی عمومی سایت |
| خودرو۴۵ | کانکتور عمومی داخلی Playwright | اجرای Chromium و دسترسی عمومی سایت؛ برخی صفحات قیمت مرجعند |
| کارنامه | اتصال بیرونی `KARNAMEH_CONNECTOR_URL` یا جست‌وجوی تکمیلی | API مجاز یا سرویس جست‌وجو |
| شیپور | اتصال بیرونی `SHEYPOOR_CONNECTOR_URL` یا جست‌وجوی تکمیلی | API مجاز یا سرویس جست‌وجو |

**محدودیت:** وجود کد کانکتور یعنی امکان *تلاش* برای خواندن صفحات عمومی؛ نه تضمین HTTP 200 یا دریافت آگهی. کپچا، مسدودسازی، محدودیت 429 و تغییر ساختار سایت گزارش می‌شوند؛ سیستم آن‌ها را دور نمی‌زند.

**فرمت اتصال بیرونی:** آدرس `*_CONNECTOR_URL` یک endpoint تحت کنترل شماست که از `POST` JSON با فیلدهای `brand, model, trim, year, mileage, condition, query`، داده `{"items":[{"url":"https://...", "title":"...", "price":2500000000, "year":1403, "mileage":50000, "kind":"listing", "trim":"پرایم"}]}` بازمی‌گرداند. قیمت بر حسب **تومان** است. URL باید به همان سایت منبع تعلق داشته باشد. صفحه/آگهی باید در برابر اطلاعات کاربر بررسی شود؛ آگهیِ بدون قیمت/تطابق یا داده نامعتبر وارد بازه نمی‌شود.

## ۲. استقرار

۱. فایل ZIP نسخه ۲۹ را استخراج کنید؛ **خود پوشه‌ای که `Dockerfile`, `backend/` و `frontend/` دارد** باید مبنای انتشار Docker روی Liara باشد.

۲. Environment را تنظیم کنید (مقادیر محرمانه را فقط در محیط Liara وارد کنید):

```env
ADMIN_PASSWORD=رمز_قوی_اختصاصی
SESSION_SECRET=رشته_تصادفی_حداقل_۳۲_کاراکتری_انگلیسی
DB_PATH=/app/data/davoodi.db
MARKET_FETCH_MODE=playwright
MAX_CONCURRENT_BROWSERS=1
MAX_DETAIL_PAGES_PER_SOURCE=6
MAX_FALLBACK_DETAIL_PAGES=5
SEARCH_CACHE_TTL=900
EMPTY_RESULT_CACHE_TTL=45
```

۳. برای ذخیره تاریخچه و خطاها پس از انتشار مجدد، **دیسک پایدار Liara را روی `/app/data` متصل کنید**. بدون دیسک پایدار، SQLite در بازسازی کانتینر از بین می‌رود.

۴. اتصال بیرونی `KARNAMEH_CONNECTOR_URL` و `SHEYPOOR_CONNECTOR_URL` یا کلید جست‌وجوی مجاز `AVALAI_API_KEY` را در صورت داشتن آن تنظیم کنید. این مقادیر اختیاری‌اند؛ در نبود آن‌ها، این دو منبع باید با وضعیت «تنظیم نیست/بررسی نشد» نمایش داده شوند.

۵. Build باید `test_v26_playwright.py`، `test_v27_reliability.py`، `test_v28_name_only.py` و `test_v29_sources.py` را اجرا کند؛ سپس Chromium بدون دسترسی root در تصویر نهایی تست شود. خطای هر کدام باید Build را شکست دهد.

## ۳. کنترل خروجی

- **`GET /api/health`:** نسخه باید دقیقاً `29.0.0-source-verified-simple-market` باشد.
- **`GET /api/readiness`:** بانک اطلاعاتی و حالت `playwright` را تأیید کنید. این پاسخ به معنی سالم بودن بازار خارجی نیست.
- **بعد از ورود `GET /api/browser-check`:** مرورگر Chromium/JavaScript را تست می‌کند.
- **بعد از ورود `GET /api/source-health`:** برای هر سایت `status`، `last_attempt_at`، `last_verified_price_at`، `last_error_at`، `raw_count` و `accepted_count` را نشان می‌دهد. زمان‌ها Unix UTC هستند.
- **جست‌وجوی «فیدلیتی»:** گروه‌های مختلف سال/تیپ/صفر-کارکرده جدا شوند، لینک‌های واقعی سایت‌ها کنار قیمت بیایند و هیچ قیمت مخلوطی تولید نشود.
- **درستی قیمت:** پنج تا ده آگهی مرتبط قابل دسترس را باز کنید و تیپ، مدل، سال، کارکرد و **قیمت داخل صفحه** را با خروجی مقایسه کنید. تا قبل از این اعتبارسنجی، **صحت قیمت زنده تأیید نشده** است.

## ۴. رفتار صادقانه در اختلال

- اگر سایت به سرور جواب نداد: `connector_error`، `rate_limited` یا `error`.
- اگر سایت کانکتور فعال ندارد و کلید جست‌وجو نیز تنظیم نیست: `not_configured`، بدون زمان بررسی جدید.
- اگر آگهی دریافت شد ولی تطابق/قیمت تأیید نشد: `no_valid_evidence`.
- `last_verified_price_at` فقط هنگامی به‌روزرسانی می‌شود که نمونه قیمت‌دار پس از اعتبارسنجی پذیرفته شده باشد؛ خطا آن را پاک نمی‌کند.
- اگر قیمت معتبری نیست، از عدد یا بازه ساختگی استفاده نکنید.

**این بسته یک نرم‌افزار مستقرشده در حساب Liara نیست.** باید با دسترسی کاربر منتشر شود. تا Build و آزمون آگهی‌های واقعی تأیید نشود، نمی‌توان پوشش زنده شش سایت یا دقت بازار را تضمین کرد.
