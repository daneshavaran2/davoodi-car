# اصلاح تشخیص گفتاری مدل خودرو

## گزارش مشکل
کاربر عبارت «خودرو فیتیلی» را گفته و سامانه برند/مدل را «نامشخص» نمایش داده است. نزدیک‌ترین نام شناخته‌شده «فیدلیتی» است، ولی باید قبل از استعلام از کاربر تأیید گرفته شود.

## تغییرات ثبت‌شده
- `backend/vehicle_recognition.py`: نرمال‌سازی فارسی، فرهنگ نام‌های جایگزین، تطبیق تقریبی و بازگرداندن گزینه قابل تأیید
- `backend/voice_vehicle_api.py`: API مستقل `POST /api/recognize-vehicle`
- `backend/tests/test_vehicle_recognition.py`: تست‌های پایه برای فیدلیتی، غلط گفتاری و متن نامعتبر

## اتصال به برنامه فعلی
فایل اصلی `backend/main.py` هنوز در GitHub موجود نیست. وقتی سورس اصلی منتقل شد، **به‌جای تعریف دوباره** `/api/parse-voice`، تابع `recognize_vehicle(text)` را در پردازش فعلی صدا بزنید و نتیجه را با اطلاعات استخراج‌شده سال/کارکرد ترکیب کنید. در صورت نیاز API مستقل را با `app.include_router` اضافه کنید.

## رفتار رابط کاربری
۱. متن گفتار بدون تغییر نمایش داده شود.
۲. برای عبارت مبهم، پیشنهاد «آیا منظورتان فیدلیتی (بهمن موتور) است؟» ارائه شود.
۳. بعد از تأیید، برند و مدل پر شوند؛ سال، تیپ و کارکردِ نگفته‌شده همچنان نامشخص بمانند.
۴. گزینه «اصلاح دستی» و «بررسی مجدد» در دسترس باشد.
۵. بدون تأیید یا شواهد کافی، قیمت تخمینی جعلی نمایش داده نشود.

## وضعیت تحویل
کد و تست در GitHub ثبت شده‌اند، ولی به علت نبودن `backend/main.py` و سورس رابط کاربری، اتصال نهایی و استقرار نسخه آنلاین هنوز انجام نشده است.
