# نسخه ۳۰.۳ — جست‌وجوی صوتی و تشخیص علت نبود قیمت

## ورودی با صدا
دکمه میکروفن کنار جست‌وجو قرار گرفت. در Chrome/Edge با پشتیبانی Web Speech API کاربر نام خودرو را به فارسی می‌گوید؛ بعد از دریافت عبارت نهایی، همان نام به API فعلی جست‌وجوی PostgreSQL فرستاده می‌شود. میکروفن به مجوز مرورگر و HTTPS نیاز دارد. روی بعضی مرورگرها/گوشی‌ها SpeechRecognition در دسترس نیست؛ پیام راهنمای تایپ نمایش داده می‌شود. سرویس تشخیص گفتار ممکن است از زیرساخت ابری شرکت سازنده مرورگر استفاده کند؛ صوت به سرور DavoodiCar ارسال یا ذخیره نمی‌شود.

## علت اینکه «آگهی معتبر کافی نداریم» زیاد نمایش داده می‌شود
- فایل ۶۶۰ مدل خودرو **فقط کاتالوگ** است و قیمت واقعی ندارد.
- شش منبع Worker در نصب پیش‌فرض غیرفعال‌اند. تنها فعال‌کردن گزینه منبع بدون تنظیم `SOURCE_<CODE>_API_URL` مجاز و قابل دسترس، قیمت تولید نمی‌کند.
- Worker فقط فیدهای/APIهای مجاز پیکربندی‌شده را می‌خواند. روی API جست‌وجوی کاربر هیچ Playwright یا دریافت مستقیم از سایت‌ها انجام نمی‌شود.
- بازه تنها وقتی ساخته می‌شود که در یک گروه سازگار (مدل، سال، تیپ، صفر/کارکرده و سایر مشخصات) دست‌کم ۵ آگهی معتبر باشد.
- نتایج محاسبه‌شده قدیمی‌تر از ۲۴ ساعت برای کاربر پنهان می‌شوند، تا قیمت قدیمی به‌عنوان امروز نمایش داده نشود.

در نسخه ۳۰.۳ پیام API بین **`sources_inactive`**، **`no_verified_prices`** و **`insufficient_sample`** تمایز می‌گذارد و تعداد منابع فعال و گروه‌های دارای قیمت را بدون نمایش کلیدها به UI می‌فرستد.

## کنترل واقعی در Liara
۱. `/api/live` را چک کنید؛ باید JSON زنده بودن سرور را برگرداند.

۲. `/api/v1/health` را چک کنید؛ باید اتصال PostgreSQL و موجودبودن ۶۶۰ مدل را تأیید کند.

۳. به مدیریت منابع در وب‌اپ بروید و با `ADMIN_TOKEN` وضعیت شش منبع، آخرین اجرای Worker و کدهای خطا را ببینید. رمز ادمین و توکن Liara یکی نیستند.

۴. در سرویس مستقل Worker با همان `DATABASE_URL`، مسیر `/api/worker/health` و لاگ‌های `WORKER_LOOP_STARTED` را بررسی کنید.

۵. برای دریافت قیمت واقعی ابتدا دسترسی مجاز به فید یک یا چند منبع لازم است. آدرس‌ها را با `SOURCE_BAMA_API_URL`، `SOURCE_DIVAR_API_URL` و مشابه آن فقط در Environment سرویس Worker تعریف کنید. سپس منبع را در ادمین فعال کنید و یک اجرای واقعی را بررسی کنید. اگر خطای `ACCESS_NOT_CONFIGURED`، `HTTP_403` یا `HTTP_429` ثبت شد، بدون دورزدن محدودیت باید منبع/مجوز اصلاح شود.

**آزمایش آفلاین به‌معنی دریافت قیمت زنده نیست.** تا زمانی که Worker داده کافی وارد نکرده باشد، سیستم عمداً عددی به‌عنوان بازه قیمت نمی‌سازد.
